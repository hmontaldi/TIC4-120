01 · Introducción

El mecanismo como caso de uso del software

No vamos a calcular ni diseñar mecanismos: vamos a explorar, desde la informática, qué tipo de programas existen para representar poleas, engranajes y transmisiones en una computadora, y cómo se usan.

◇ ENFOQUE DE LA CLASE

Software como herramienta

Cada simulador es, ante todo, un programa: tiene una interfaz, archivos propios, menús y una lógica de uso que se puede aprender.

Distintas categorías

No todo el software que "simula mecanismos" hace lo mismo: hay programas de diseño, de animación y de cálculo, cada uno con un objetivo distinto.

Software libre

Vamos a trabajar con programas gratuitos y de código abierto, disponibles para instalar en cualquier computadora del laboratorio.

02 · Categorías de software

¿Qué tipos de programas existen?

Antes de abrir cualquier programa, conviene entender en qué categoría entra y para qué sirve cada una.

Software de diseño (CAD)

Permite dibujar y armar piezas en 3D dentro de la computadora: por ejemplo, modelar una polea o un engranaje y unirlos en un conjunto.

Software de cálculo

Toma un modelo ya hecho y calcula automáticamente valores (esfuerzos, movimientos, relaciones) que sería muy lento calcular a mano.

En esta clase vamos a explorar un ejemplo de cada categoría: uno para diseñar y armar conjuntos, y otro para calcular.

03 · Herramientas

Software libre para instalar y explorar

Dos programas gratuitos, disponibles para Windows y Linux, ideales para empezar a explorar sin costo.

FreeCAD

Programa libre de diseño paramétrico en 3D. Permite abrir o crear piezas y armarlas en un conjunto que se puede mover en pantalla.

  • Interfaz organizada en "bancos de trabajo", cada uno con sus propias herramientas.
  • Los archivos se guardan con su propia extensión (.FCStd).
  • Tiene una gran comunidad de usuarios y documentación en español.
GratuitoCódigo abiertoWindows / Linux

Mecway

Programa de cálculo por elementos finitos, con una versión gratuita para modelos simples. Recibe una pieza y devuelve resultados numéricos y gráficos.

  • Se puede importar un modelo hecho en otro programa (como FreeCAD).
  • Muestra los resultados con colores sobre la pieza, fáciles de interpretar.
  • La versión gratuita alcanza para explorar el funcionamiento del programa.

05 · Actividad de laboratorio

Guía de exploración guiada

Trabajo en parejas, en el laboratorio de informática. Duración estimada: un módulo de 80 minutos.

  1. Instalar o abrir FreeCAD en la netbook y recorrer su interfaz: identificar la barra de bancos de trabajo, el árbol de modelo y el área de dibujo.

  2. Abrir un ejemplo de conjunto con engranajes o poleas (de la galería de ejemplos del programa o provisto por el docente) y observar cómo está organizado en piezas.

  3. Identificar tres funciones del programa que sirvan para armar o mover ese conjunto (por ejemplo: restricciones, medidas, rotación de vista).

  4. Abrir Mecway y explorar su interfaz: dónde se importa un modelo, dónde se definen las cargas y dónde se ven los resultados.

  5. Completar una ficha comparativa (provista por el docente) indicando, para cada programa: para qué sirve, qué tipo de archivo genera y una captura de pantalla de su interfaz.

  6. Puesta en común: cada pareja muestra su ficha y comenta una función del software que le resultó útil o difícil de encontrar.

06 · Glosario

Términos clave

Software libre
Programa cuyo código fuente puede ser visto, modificado y redistribuido libremente por cualquier usuario.
Software paramétrico
Programa en el que el modelo se define con valores (parámetros) que, al cambiarlos, actualizan el dibujo automáticamente.
Banco de trabajo
En FreeCAD, conjunto de herramientas agrupadas según una tarea específica (por ejemplo, dibujar o ensamblar).
Elementos finitos (FEA)
Método de cálculo que usa una computadora para dividir una pieza en partes pequeñas y obtener resultados numéricos.
Formato de archivo
Manera en que un programa guarda su información; cada software suele tener su propia extensión de archivo.
Interfaz
Conjunto de menús, botones y paneles que permiten a una persona interactuar con un programa.
07 · Autoevaluación

Comprobá lo aprendido

1. ¿Qué caracteriza a un software de diseño paramétrico como FreeCAD?

Lo distintivo del diseño paramétrico es que el dibujo se recalcula solo cuando se modifica un valor del modelo.

2. ¿Qué hace principalmente un software de cálculo como Mecway?

Mecway recibe un modelo, aplica condiciones y devuelve resultados numéricos y gráficos, no se usa para diseñar piezas desde cero.

3. ¿Qué es un "banco de trabajo" en FreeCAD?

Cada banco de trabajo agrupa las herramientas necesarias para una tarea puntual, como dibujar o ensamblar piezas.
