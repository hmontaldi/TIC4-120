SECCIÓN I: Opción Múltiple (5 preguntas x 6 pts c/u = 30 pts)

Marque con una opción en cada ítem.

1. ¿A qué se refiere el criterio de escalabilidad al seleccionar un software?

2. Un taller mecánico necesita un sistema para cargar repuestos y consultar el stock desde el celular o cualquier PC sin instalar nada localmente. ¿Qué modalidad es la mejor opción?

3. ¿Qué beneficio clave ofrece el Software Libre / Open Source frente al Software Propietario en el ámbito escolar?

4. Una PYME quiere implementar un nuevo sistema, pero sus empleados no tienen experiencia técnica. ¿Qué criterio técnico cobra mayor relevancia?

5. Si un usuario necesita organizar grandes volúmenes de registros numéricos y generar gráficos estadísticos para un informe, ¿qué categoría de software debe elegir?

SECCIÓN II: Verdadero o Falso (5 ítems x 4 pts c/u = 20 pts)

Seleccione V o F según corresponda.

Afirmación V F
1. El costo total de un software comercial solo incluye el pago único de la licencia de compra.
2. La portabilidad indica si un software puede ejecutarse en diferentes plataformas o sistemas operativos.
3. Un software discontinuado o sin soporte técnico sigue siendo seguro si la PC no tiene virus.
4. Las aplicaciones Web (SaaS) dependen indispensablemente de una conexión a Internet estable para funcionar plenamente.
5. Un software con "Adecuación Funcional" cumple exactamente con las tareas específicas que el usuario necesita resolver.

SECCIÓN III: Unir con Flechas / Relacionar (5 pares x 4 pts c/u = 20 pts)

Tipo de problema / Necesidad Resp. Software adecuado
1. Un estudiante necesita editar un video para un proyecto escolar sin pagar licencias. A. Editor de gráficos vectoriales (Inkscape, Illustrator).
2. Diseñar un logotipo profesional escalable que no pierda calidad al ampliarlo. B. Navegador web moderno (Chrome, Firefox).

SECCIÓN IV: Caso Práctico (20 pts)

Situación: Una radio FM comunitaria de un municipio pequeño quiere organizar su archivo de audios (programas grabados y música). Disponen de dos computadoras antiguas con sistema operativo Linux, no cuentan con conexión a internet en la sala de edición y el personal técnico está integrado por voluntarios con conocimientos informáticos básicos.
A. (8 pts) Mencioná tres criterios de selección fundamentales para evaluar el software de edición de audio en este escenario y explicá brevemente por qué.
B. (7 pts) ¿Qué programa de edición de audio (ej: Audacity, Pro Tools, etc.) o tipo de licencia recomendarías? Justificá con 2 argumentos basados en las restricciones del caso.
C. (5 pts) ¿Qué inconveniente o desventaja podría presentarse al trabajar con equipos antiguos y software libre en este entorno?
