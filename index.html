Criterios según el problema a resolver · Prof. Humberto Montaldi

¿Por qué importa elegir bien el software?

Elegir un software es una decisión estratégica, no solo técnica. El software equivocado puede hacer que un problema sencillo se vuelva imposible de resolver.

Imaginá que necesitás llevar el registro de ventas de un negocio. Podrías usar:

📝

Un bloc de notas

Funciona para 5 ventas al día. Imposible para 500 productos y múltiples vendedores.

📊

Una planilla de cálculo

Mucho mejor: permite fórmulas, filtros y gráficos. Pero no está diseñada para ventas en tiempo real.

🖥️

Un sistema de gestión (ERP)

Diseñado exactamente para esto. Inventario, facturación y reportes integrados.

💡 Concepto clave No existe el "mejor software" en términos absolutos. Existe el software más adecuado para un problema específico, un usuario específico y un contexto específico.

¿Qué entendemos por "problema a resolver"?

Antes de elegir cualquier herramienta, necesitamos definir con claridad:

  • ¿Qué tarea se debe realizar? (editar texto, calcular, diseñar, programar, comunicarse…)
  • ¿Quién lo va a usar? (un experto, un usuario sin formación técnica, muchas personas a la vez)
  • ¿En qué entorno? (computadora de escritorio, celular, red empresarial, sin conexión a internet)
  • ¿Con qué recursos? (presupuesto disponible, tiempo de aprendizaje, infraestructura existente)
📌 Para recordar Primero se analiza el problema, después se busca el software. Nunca al revés.

Criterios de selección

Estos son los ocho criterios fundamentales que se evalúan al elegir un software para resolver un problema.

1. Adecuación funcional

¿El software hace lo que el problema necesita? Se verifican las funciones mínimas necesarias antes de considerar cualquier otro aspecto.

¿Cubre las tareas requeridas? ¿Sin adaptaciones complejas?

2. Facilidad de uso (usabilidad)

Un software muy potente que nadie sabe usar no sirve. Se evalúa si la interfaz es intuitiva y si el tiempo de aprendizaje es razonable para los usuarios.

Interfaz clara Curva de aprendizaje

3. Compatibilidad e integración

¿Funciona en los sistemas operativos disponibles? ¿Puede intercambiar datos con otros programas que ya se usan?

Windows / Linux / Android Formatos de archivo

4. Costo y licenciamiento

Existen distintos modelos: software libre, propietario con licencia única, suscripción mensual (SaaS) o freemium. El costo total incluye adquisición, capacitación y mantenimiento.

Open source Licencia Suscripción

5. Seguridad y privacidad

¿Qué datos maneja el software? ¿Están protegidos? Especialmente importante cuando se manejan datos personales o información sensible.

Cifrado Control de accesos Backups

6. Escalabilidad

¿El software podrá seguir funcionando bien si el problema crece? Una solución que sirve para 10 usuarios puede colapsar con 500.

Crecimiento futuro Rendimiento

7. Soporte y documentación

¿Hay asistencia técnica disponible? ¿La documentación está en español? ¿Existe una comunidad activa que resuelva dudas?

Soporte oficial Foros Tutoriales

8. Continuidad del proyecto

¿El software sigue siendo desarrollado y actualizado? Un software abandonado acumula vulnerabilidades de seguridad y deja de ser compatible con sistemas nuevos.

Actualizaciones Comunidad activa
⚠️ Atención Ningún criterio actúa solo. En la práctica se evalúan todos en conjunto y se priorizan según las necesidades del caso. Por ejemplo: para una institución escolar, el costo suele ser el criterio más restrictivo.

¿Software libre o propietario?

🔓

Software Libre / Open Source

El código fuente es público. Se puede usar, copiar, modificar y distribuir. Generalmente gratuito.

✔ Sin costo de licencia ✔ Comunidad activa ✔ Auditable

🔒

Software Propietario

El código es privado. Se usa bajo licencia comercial. Suele tener soporte técnico oficial.

✔ Soporte garantizado ✔ Actualizaciones regulares ✘ Costo de licencia

☁️

SaaS (Software como servicio)

Se usa desde el navegador, sin instalar. Se paga por suscripción mensual o anual.

✔ Siempre actualizado ✔ Acceso desde cualquier lugar ✘ Requiere internet

📚 Ejemplo del aula En la escuela usamos LibreOffice (libre), Google Drive (SaaS gratuito con cuenta educativa) y a veces Windows (propietario, con licencia institucional). Cada uno fue elegido según el contexto y el costo disponible.

Proceso de selección paso a paso

Seleccionar software de forma ordenada evita errores costosos. Este proceso de seis pasos aplica tanto en empresas como en proyectos escolares.

1
Definir el problema con precisión

¿Qué necesitamos resolver exactamente? Cuanto más específica sea la definición, más fácil será encontrar la solución correcta.

2
Identificar requisitos funcionales y no funcionales

Funcionales: lo que el software debe hacer. No funcionales: cómo debe hacerlo (rápido, seguro, fácil de usar, en español…).

3
Relevar opciones disponibles

Investigar qué software existe para ese tipo de problema. Consultar reseñas, comparativas y opiniones de otros usuarios.

4
Comparar según criterios ponderados

No todos los criterios tienen el mismo peso. Si el presupuesto es cero, el costo es el filtro más importante. Asignar prioridades según el contexto.

5
Realizar una prueba piloto

Instalar o probar la versión demo del software con un caso real o simulado. Verificar que efectivamente resuelve el problema antes de comprometerse.

6
Tomar la decisión y documentarla

Elegir la opción mejor puntuada y registrar los motivos de la decisión. Esa documentación es útil si en el futuro hay que revisar la elección.

Ejemplo práctico: elegir software para editar el diario escolar

// Problema: el centro de estudiantes necesita editar un boletín mensual en PDF Requisitos funcionales: - Insertar texto e imágenes - Exportar a PDF - Diseño de página libre (no solo párrafos) Requisitos no funcionales: - Gratis (presupuesto = $0) - Funcionar sin internet - Varios alumnos puedan editar Opciones evaluadas: Word → ✘ requiere licencia paga Google Docs → ✘ requiere internet siempre Canva → ✘ versión gratis limitada + requiere internet LibreOffice Impress → ✔ libre, offline, flexible para diseño Decisión: LibreOffice Impress ← mejor relación criterio/contexto
🎯 Clave La "mejor" opción no es la más conocida ni la más cara. Es la que mejor responde a los criterios del problema en ese contexto particular.
